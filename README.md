# InCaseI4Get

InCaseI4Get 是一款面向海外日常生活的 iOS 提醒 App。用户可以通过按住说话或文字输入，用一句话记录「几时做什么事」；到点时 App 用任务文字、语音播报、触感和闪光进行多模态提醒，覆盖能说话、能听见以及听障、语障等不同类型用户。

App 不需要账号或密码，不登录、不追踪、不建档案。所有提醒数据只保存在用户本机。

完整的方案基线见 [docs/implementation-plan.md](docs/implementation-plan.md)。

## 第一版范围

- 按住说话与文字输入两个平等入口。
- 语音/文字共用首批支持语言的时间解析：自动拆出任务与提醒时间。
- SwiftData 本地保存，无账号、无云端。
- 到点全屏提醒确认屏，未点击「收到」前不消失。
- 前台多模态：文字 + TTS + 触感 + 屏幕闪光。
- 锁屏/后台：任务文字横幅 + 预生成任务语音通知声音。
- 提前提醒，以及 30/60 秒强袭补发。
- 通知动作：收到、10分钟后再提醒。
- 单次、每日、每周、每月提醒；重复任务可设置结束日期，例如护士连续 7 天每天同一时间换药。
- 当天有效的一次性任务在本地零点过后自动清理。

联网 AI 任务解析、AI 口语化提醒文案与云音色属于二期可选能力，默认不启用，技术预案见 [docs/ai-plan.md](docs/ai-plan.md)。

## 隐私基线

- 不需要账号、密码、手机号或第三方登录。
- 不采集身份信息，不做行为追踪，不接入广告或分析 SDK。
- 提醒数据、转写文本、设置和语音提醒文件全部保存在本机。
- 删除提醒或清除全部数据后，本机不留残留记录。
- 语音识别优先使用设备端识别；设备不支持的场景不静默上传原始录音。
- 默认版本 App Store 隐私标签按「不收集数据」申报；若开放联网 AI，需重新确认功能与标签口径。

## 技术基线

- Xcode 15 或更新版本
- iOS 17.0+
- SwiftUI + SwiftData
- `UserNotifications` 做锁屏/后台本地通知
- `Speech` 按用户语言做语音转写
- `AVSpeechSynthesizer` 按用户语言做 TTS
- 本地通知自定义声音承载预生成任务语音
- 无第三方依赖

## 在 Mac 上运行

1. 把整个目录同步到 Mac。
2. 用 Xcode 打开 `InCaseI4Get.xcodeproj`。
3. 在 Signing & Capabilities 里选择你的开发团队。
4. 选择真机或模拟器运行。

注意：本目录在 Windows 上生成，无法用 Xcode 直接编译验证；首次在 Mac 打开后若 Xcode 提示调整工程设置，按 Signing 步骤处理即可。

## iOS 平台边界

- iOS 不开放自定义通知振动强度，锁屏振动遵循用户系统设置。
- iOS 不允许锁屏/后台控制摄像头闪光灯；锁屏闪光需引导用户开启系统 LED 闪光提醒。
- 后台无法保证实时合成任意文字的语音；锁屏朗读采用保存时生成的语音通知文件。
- 强袭补发是预排的本地通知，不是后台实时监听。

## 当前状态

当前目录包含一版原生 SwiftUI 工程：文字输入和语音转写都会转换为统一的 `ReminderDraft`，再进入同一个确认页和保存服务；保存服务统一负责 SwiftData、通知授权、通知排程和提醒语音文件。已实现无账号本地存储、单次/每日/每周/每月提醒、本地通知、全屏多模态提醒、设置与本地数据清理。

该版本尚未在当前 Windows 环境完成 Xcode 编译和真机验证。10 种语言的界面文案和基础重复词解析已存在，通知语音文件也已接入，但日期时间解析仍主要依赖系统 `NSDataDetector`，尚未形成覆盖 10 种语言的完整规则库和评测集。
