# InCaseI4Get 第一版任务清单

## M0：工程与权限

- [ ] 在 Xcode 中确认工程可编译运行。
- [ ] 确认 App 无账号、无登录、无第三方分析依赖。
- [ ] 配置 Bundle ID、开发团队和 iOS 17 部署目标。
- [ ] 加入九种语言的本地化资源目录。
- [ ] Info.plist 权限用途文案完成多语言覆盖。
- [ ] 注册本地通知分类与「收到」「10分钟后再提醒」动作。
- [ ] 写一个空首页，跑通通知授权。

验收：真机运行不崩溃，授权文案在当前系统语言下正确显示。

## M1：数据与一句话解析

- [ ] `ReminderItem` 完成：任务、备注、时间、提前分钟、强袭、完成状态、来源、解析状态。
- [ ] 九种发布语言各自支持数字、日期、时段与相对时间。
- [ ] 解析器能把时间词从任务文字中移除。
- [ ] 解析失败时返回未识别状态。

验收：相同句子在语音与文字两条链路中解析结果一致；解析规则按语言正确切换。

## M2：通知调度

- [ ] 保存时调度提醒。
- [ ] 完成/删除时取消对应通知。
- [ ] 提前提醒可选。
- [ ] 强袭模式下 30 秒、60 秒补发。
- [ ] 「10分钟后再提醒」能重排通知。

验收：不处理时能收到至少三条通知；点收到后全部停止。

## M3：任务语音文件

- [ ] 保存时按提醒语言把任务内容生成通知声音。
- [ ] 任务内容修改后重新生成。
- [ ] 删除提醒后清理声音文件。
- [ ] 通知自定义声音能播放任务内容。

验收：锁屏状态下创建提醒后，通知响铃语言与任务文字语言一致。

## M4：首页与文字新增

- [ ] 首页时间线：今天、后续、已经过了。
- [ ] 首页提供明显的「打字记一条」入口。
- [ ] 文字新增支持完整句子解析。
- [ ] 时间未识别时强制用户补充。
- [ ] 行内完成与左滑删除。
- [ ] 文字输入页完成九种语言与 RTL 适配。

验收：不使用麦克风也能完成新增、到点、确认完整流程。

## M5：按住说话

- [ ] 按住首页麦克风录音。
- [ ] 录音时实时显示转写文字，并优先设备端识别。
- [ ] 松开后进入解析确认页。
- [ ] 语音不可用时保留文字入口。
- [ ] 权限被拒时有明确文字反馈。
- [ ] 语音识别使用当前界面语言的 locale。

验收：说「明天下午3点去接女儿」得到任务与时间预填。

## M6：前台多模态提醒

- [ ] 到点时自动弹出全屏提醒确认屏。
- [ ] 屏幕展示任务文字，未确认不消失。
- [ ] TTS 同步朗读任务内容。
- [ ] 触感反馈触发。
- [ ] 屏幕闪光可开关。

验收：前台到点同时出现文字、语音、触感、闪光。

## M7：冷启动与设置

- [ ] 点开通知后先进提醒确认屏。
- [ ] App 被杀后能补处理未完成的通知动作。
- [ ] 设置页覆盖播报、提前分钟、强袭、触感、闪光、音量。
- [ ] 设置页支持跟随系统语言或手动切换 App 语言。
- [ ] 提供系统 LED 闪光提醒设置入口。
- [ ] 设置页提供清除全部本地数据的二次确认流程。
- [ ] 减弱动态效果时不使用高强度闪烁。

验收：杀 App 后点通知，仍能看到全屏任务文字并完成确认。

## M8：无障碍与真机边界

- [ ] VoiceOver 覆盖首页、新增页、提醒屏、设置页。
- [ ] 动态字体下无文字截断。
- [ ] 真机测试锁屏、勿扰、后台、飞行模式。
- [ ] 关闭声音、闪光、触感时分别验证提醒仍可感知。
- [ ] 九种语言各自抽查文字、TTS、语音识别、时间解析。
- [ ] 阿拉伯语完整验证 RTL 布局。

验收：听障/语障用户只使用文字能完成全部核心流程；提醒至少保留一种不依赖声音的感知方式。

## M9：海外发布准备

- [ ] 英文作为默认回退语言，避免本地化缺失时出现英文/中文混排。
- [ ] App Store 名称、副标题、关键词与截图按海外市场准备。
- [ ] 通知动作与权限文案通过九种语言审核清单。
- [ ] 验证 12/24 小时制、日期顺序与星期起点差异。
- [ ] 验证每种语言在模拟器和真机上的语音识别与 TTS 可用性。
- [ ] App Store 隐私标签确认不收集数据。
- [ ] 删除单条与清除全部数据后验证无残留。

验收：九种语言全部满足「文字录入 → 时间解析 → 保存 → 到点多模态提醒」闭环。
