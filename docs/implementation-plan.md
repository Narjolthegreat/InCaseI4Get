# InCaseI4Get 实现大纲

版本：方案基线 0.3

## 1. 产品目标

InCaseI4Get 是一款面向日常场景的 iOS 提醒 App。用户用说话或打字记下「几时做什么事」，到点时 App 通过文字、语音、触感和闪光多模态提醒，确保不同类型用户都不会漏掉。

产品采用无痕隐私基线：不需要账号与密码，不登录、不追踪、不建用户档案，所有提醒内容只保存在用户自己的设备上。

用户模型包含：

- 能说话、能听见的用户。
- 听障、语障等无法使用语音输入的用户。
- 对声音、视觉或触感敏感程度不同的用户。

### 市场与语言

- 主要市场为海外。
- 首批支持 English、日本語、한국어、Français、Deutsch、Türkçe、中文、Español、Português、Русский。
- App 文案、通知动作、语音识别、TTS 与时间解析都按用户语言工作。
- 中文首轮支持简体中文（zh-Hans），繁体中文后续再补充。

### 隐私基线

- 永不引入账号、密码、手机号或第三方登录。
- 不采集身份信息，不做行为追踪，不接入广告或分析 SDK。
- 提醒数据、设置、转写文本与语音提醒文件只保存在本机。
- 删除提醒或清除全部数据后不留残留副本。
- 语音识别优先使用设备端识别；离线识别不可用时给出说明，不静默上传原始录音。
- App Store 隐私标签按「不收集数据」申报。

## 2. 第一版范围

第一版包含：

- 按住说话新增提醒。
- 文字输入新增提醒，与语音平等。
- 首批 10 种语言的一句话时间解析：从一句话里拆出任务内容与提醒时间。
- 首批 10 种语言的 UI 文案、通知动作、TTS、语音识别与系统权限说明。
- SwiftData 本地持久化。
- 本地通知调度、取消、提前提醒与 30/60 秒强袭补发。
- 单次提醒，以及每日/每周/每月的重复提醒；重复任务可设结束日期，支持护士连续 7 天每天换药这类场景。
- 前台多模态提醒屏：文字 + TTS + 触感 + 屏幕闪光。
- 锁屏/后台通知使用预生成任务语音文件。
- 通知动作：收到、10分钟后再提醒。
- 冷启动后继续处理未完成的提醒动作。
- 基础无障碍支持与权限引导。
- 无账号、无登录、无云端同步的完整本地数据生命周期。

第一版不包含：

- 联网 AI 语义解析与联网自然文案生成。该能力作为二期可选功能，完整约束见 [docs/ai-plan.md](docs/ai-plan.md)。
- 订阅与支付体系。
- 自定义音色录制。
- 全局语音查询。
- 云端同步。

## 3. 输入通道

两个输入通道共用同一套解析与保存链路：

- 语音通道：首页按住说话 → 转写 → 一句话解析 → 确认保存。
- 文字通道：首页「打字记一条」→ 输入句子 → 一句话解析 → 确认保存。

文字不是语音的备用项。对无法语音输入的用户，文字必须是完整的、快捷的第一入口。

语音识别、输入法、日期格式与解析语言都以当前提醒输入语言为准。首轮以 App 当前界面语言决定识别与解析语言，并允许用户在设置里手动切换。

解析结果统一为 ReminderDraft：

- 任务内容
- 提醒时间
- 是否自动识别成功
- 是否被用户手动修改
- 来源：voice 或 text
- 输入语言/区域标识

## 4. 数据模型

提醒记录字段：

- id
- 任务内容
- 备注
- 提醒时间
- 提前提醒分钟数
- 是否强袭
- 是否完成
- 创建时间
- 完成时间
- 来源（voice/text）
- 输入语言与区域标识
- 时间是否由解析器识别
- 是否由用户手动修改
- 重复类型：不重复 / 每日 / 每周 / 每月
- 重复结束日期（可选）
- 当天一次性任务的过期清理时间

本地模型容器使用 SwiftData，底层文件由系统管理。

数据生命周期完全本地化：

- 新增：文本或转写结果进入本机 SwiftData。
- 通知：本地通知与任务语音文件只生成在本机。
- 删除：单条删除或全部清除同时移除通知、语音文件与持久化记录。
- 不提供导出到账号、不同步 iCloud 自定义数据。
- 若启用系统语音识别，优先要求设备端识别，避免原始语音上传。

### 重复与过期

- 单次临时任务只在其当天有效；过了本地零点自动清理，除非它已属于重复任务。
- 每日任务可按每天固定时间无限重复，也可设置结束日期或连续天数。
- 每周任务默认固定在创建时的星期和时间重复。
- 每月任务默认固定在创建时的日期重复；不存在的日期按产品规则跳过或顺延到月末。
- 重复任务被点击「收到」时，只完成当前发生日，不删除整个重复系列；下一次按规则生成。
- 有限次重复到达结束日期后自动结束并清理。
- App 在后台被杀时无法保证零点准点执行清理；再次打开或回到前台时会立即完成过期清理，零点后过期任务不会再出现在首页。

## 5. 多模态提醒流程

触发来源分两种情况：

App 在前台：

- 自动弹出全屏提醒确认屏。
- 显示任务文字。
- TTS 朗读任务内容。
- 反复触感反馈。
- 屏幕闪光。

App 在后台或锁屏：

- 系统本地通知先出现。
- 通知横幅显示任务文字。
- 通知声音为保存时预生成的任务语音。
- 振动表现遵循系统设置。
- 用户点开通知后进入全屏提醒确认屏。

提醒确认屏状态：

- 显示任务内容、提醒时间、来源与重复规则。
- 两个操作：收到、10分钟后再提醒。
- 未操作前不自动消失。
- 强袭模式下 30 秒、60 秒补发。
- 单次任务确认后即完成；重复任务确认后跳到下一次发生，不删除重复系列。

## 6. iOS 技术边界

以下能力必须按系统规则实现：

- iOS 不提供自定义通知振动强度；锁屏振动由系统设置决定。
- iOS 不允许锁屏/后台点亮摄像头闪光灯；锁屏闪光依赖系统 LED 提醒设置。
- App 被系统杀掉后，无法在后台实时合成并朗读任意文字。
- 锁屏朗读需要把任务内容预生成为通知音频文件，并在保存时作为通知自定义声音。
- 前台才支持完整的屏幕闪光、自定义触感脉冲和实时 TTS。
- 每个支持语言都需要独立配置语音识别 locale、TTS locale 与本地时间解析规则。
- 中文、日语、韩语需要按 CJK 文字习惯处理断行、标点与日期格式。
- 语音识别优先设置设备端模式；设备或语言不支持离线识别时，应在界面说明后再决定是否使用。
- iOS 对待发本地通知数量有系统上限，开放式的每日/每周/每月任务应使用系统重复触发器；有限次数任务再展开为单条通知。
- 重复触发器无法在某个后台日期自动停止；有结束日期的重复任务需要 App 打开或回到前台时校正。
- App 被杀时无法在零点准点执行清理，只能在下次启动或回到前台时补清理过期单次任务。
- 锁屏/后台到点无法临时调用联网模型，也不能在到点实时合成语音；AI 文案必须先于到点生成，并由本地 TTS 预渲染成通知声音。

## 7. 模块划分

App 启动与权限：

- 注册通知分类。
- 处理通知授权、麦克风授权、语音识别授权。
- 记录系统设置跳转入口。
- 加载界面语言资源，并本地化全部权限说明。

数据层：

- ReminderItem 模型。
- 本地持久化与查询。
- 完成、删除、顺延。
- 每日/每周/每月规则与有限重复结束判定。
- 单次临时任务跨零点后的过期清理。
- 单条清除与全部清除的数据生命周期。

一句话解析器：

- 首批 10 种语言的数字、日期、时段、相对时间与常用句式。
- 任务文字清理。
- 解析状态返回。
- 每种语言提供独立规则表，缺失时回退到手动时间选择。

通知调度器：

- 创建、取消、更新提醒。
- 提前提醒与强袭补发。
- 通知动作路由。
- 单次与有限重复任务展开调度。
- 开放式每日/每周/每月任务使用系统重复触发器。
- 过期单次任务与已结束重复任务的清理校正。

语音音频生成器：

- 把任务内容转成通知声音。
- 内容变化时重新生成。
- 文件生命周期管理。

语音输入服务：

- 按住说话。
- 按当前语言实时转写。
- 优先使用设备端语音识别。
- 权限与失败状态。

本地化模块：

- UI 文案与通知动作多语言资源。
- TTS 与语音识别 locale 映射。
- 多语言日期与时间解析规则。
- CJK 文字排版与动态字体验证。

AI 服务（二期可选）：

- 任务结构化提取接口。
- 口语化提醒文案生成接口。
- 可替换模型供应商适配层。
- 本地解析与本地模板作为默认回退。
- 联网前的内容确认与隐私说明。

多模态提醒器：

- 全屏提醒确认屏。
- TTS 播报。
- 触感反馈。
- 屏幕闪光。

提醒动作路由器：

- 前台动作处理。
- 锁屏通知点击处理。
- 冷启动待处理动作补执行。

UI 页面：

- 首页：时间线、麦克风、文字入口、设置。
- 新增页：文字输入、解析确认与重复规则选择。
- 提醒确认屏：多模态提醒。
- 设置页：提醒策略与无障碍选项。
- 设置页提供「清除全部本地数据」入口与确认流程。

M8 真机验收：

- 锁屏、勿扰、后台、冷启动。

- 确认工程不包含广告、统计、崩溃上报等第三方 SDK。
- 按「不收集数据」填写 App Store 隐私标签。
- 验证语音识别设备端模式支持范围与界面提示。
- 验证删除提醒后通知、语音文件与本地记录同步清除。
- 验证卸载 App 后不存在残留在系统容器外的应用数据。

AI 二期候选阶段（不进入 M0-M9）：

- 验证首批 10 种语言的系统转写质量。
- 验证大模型结构化输出与本地解析器的兜底切换。
- 按用户语言生成口语化提醒文案并预渲染音频。
- 决定是否引入云端音色，并更新隐私标签与说明。

## 9. 验收标准

- 只使用文字可以完成新增、到点、确认完整闭环。
- 只使用语音也可以完成同一闭环。
- 前台到点同时出现文字、语音、触感、闪光。
- 锁屏通知能看到任务文字并听到预生成任务语音。
- 点开通知后先看到全屏任务文字，确认后才回到首页。
- 点击收到后所有补发停止。
- 关闭闪光不影响文字与语音。
- 关闭声音仍能通过文字、触感感知提醒。
- 首批支持语言下，文字录入、时间解析、通知动作与语音播报语言保持一致。
- 全程无账号与密码步骤；删除或清除数据后本机不留可恢复记录。
- 重复任务可按每日/每周/每月规则自动产生下一次提醒，并在结束日期停止。
- 当日一次性任务在本地零点过后自动隐藏或清理，不继续留在首页。
